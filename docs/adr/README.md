# Architecture Decision Records

Durable record of architecture decisions for claude-devtools. One file per decision, numbered, never edited after acceptance except to change the status (for example to `Superseded by ADR-00NN`).

## Index

| ADR | Title | Status |
|-----|-------|--------|
| [0001](0001-record-architecture-decisions.md) | Record architecture decisions | Accepted |

## Adding an ADR

1. Copy the structure of `0001-record-architecture-decisions.md`.
2. Use the next free number and a short kebab-case slug.
3. Fill in Context, Decision and Consequences. Keep it under a page.
4. Add a row to the index above.
